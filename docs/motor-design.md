# BLDC Motor Design

## Configuration
- 32 poles
- N52 magnets
- 3-phase winding
- Laminated stator core

## Design Approach
Outer rotor configuration for higher torque density.

## Winding Notes
- Even distribution required
- Tight packing improves efficiency
- Insulation critical

## Risks
- Torque ripple from uneven windings
- Overheating
- Magnet detachment
